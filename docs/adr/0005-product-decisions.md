# ADR-0005 · Продуктовые решения (биллинг, онлайн, дизайн, домен)

- **Статус:** Принято
- **Дата:** 2026-06-20

## Решение

- **Биллинг:** только B2B-подписка вуза через **ЮKassa** (Фаза 4). Оргвзносы участников и 54-ФЗ для них — НЕ в v1 (резерв roadmap).
- **Онлайн-участие:** внешние ссылки трансляций (Zoom / VK Звонки / YouTube) + встроенный чат/Q&A поверх. **Встроенного видео-стрима нет.**
- **Визуальный язык:** **академический синий** (см. `Визуальный-гайд.html`) + реализация как в `Макеты-экранов.html` (69 экранов). Токены — CSS-переменные; per-tenant перетемизация через `--brand`. Внедрение — Фаза 3.
- **Домен платформы:** выбирается ПОЗЖЕ (плейсхолдер `uni.platform.ru` в коде/доках; не `confhub.ru`).
- **Рынок/язык:** только вузы РФ, русский UI, задел на i18n/E.164 без реализации в v1.

## Опорные документы

`ТЗ-2.0`, `Дизайн-ТЗ-UX`, `Визуальный-гайд`, `Макеты-экранов`, `План-реализации` (в корне репозитория).
